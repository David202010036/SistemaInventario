# Sistema de Gestión de Inventario

Proyecto para administrar los productos y existencias de un inventario.

## Objetivo

Desarrollar una aplicación que permita registrar, consultar, modificar y eliminar productos, manteniendo organizada la información del inventario.

## Funcionalidades principales

- Registrar productos.
- Consultar y buscar productos.
- Modificar la información de un producto.
- Eliminar productos del inventario.

## Tecnologías previstas

- C#
- .NET
- Entity Framework Core
- SQL Server

## Estado del proyecto

Actualmente en etapa de planificación.
